A "Regra do Autocarro" (O Teste do Incapacitado)
Imaginem que, na segunda-feira, vocês ganham a lotaria e não voltam à
Organização. O que acontece à empresa? Se a resposta for "a empresa pára", vocês
não construíram um sistema, construíram uma prisão para vocês mesmos.
• A Ação: O vosso sistema tem de ser tão óbvio que qualquer colega, com o
manual que vocês criaram, consiga ver o relatório de vendas.
• O Teste: Se o vosso colega não conseguir abrir o Excel e clicar em "Atualizar",
o sistema ainda é "vosso" e não "da empresa". Simplifiquem até que um
leigo consiga usar.
Passo 2: O "Manual de Instruções de 1 Página" (O README literal)
Esqueçam documentos Word de 20 páginas. Ninguém lê. Criem um documento
chamado COMO_FUNCIONA.txt e coloquem-no na pasta do projeto.
• O conteúdo tem de ter apenas 3 secções:
1. Onde estão os dados: ("Os dados de vendas estão na base
Organização").
2. Como atualizar: ("Abram o Excel, carreguem no botão 'Atualizar
Dados' no menu Dados").
3. O que fazer se der erro: ("Se aparecer um erro, chamem o [Nome de
um colega que vocês treinaram]").

COMO VER AS VENDAS:

1. Abrir o ficheiro 'Relatorio_Vendas.xlsx'.
2. Clicar no separador 'Dados' lá em cima.
3. Clicar no botão 'Atualizar Tudo'.
4. Se pedir uma senha, é [A vossa senha].

SE DER ERRO:

1. Verificar se o computador tem internet.

2. Se o erro persistir, enviar um print screen do erro para o e-mail:
[vosso_email@empresa.com].

• Literal: Se o sistema avariar, o Diretor lê isto e sabe quem chamar. Vocês
deixam de ser os bombeiros de serviço. Qualquer pessoa que saiba ler,
consegue seguir estes 4 passos. Se ela conseguir ver as vendas, vocês não
precisam de lá estar.
